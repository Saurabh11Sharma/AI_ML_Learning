# AI / ML Learning Vault

An Obsidian-oriented workspace for organising AI and machine-learning study material, research references and experiments.

## Vault navigation

| Folder | Intended contents |
|---|---|
| 00_Overview | Vault orientation and topic index |
| 01_Roadmap | Learning paths and topic sequencing |
| 02_Lectures | Lecture notes and course material |
| 03_Papers | Research paper reading notes |
| 04_Projects | Experiments and project work |
| 05_Resources | Reference links and supporting material |
| 06_Templates | Reusable note templates |
| 07_Journals | Learning journal and progress notes |

## Suggested workflow

1. Choose a topic from the roadmap.
2. Capture a concise explanation in your own words.
3. Link source material and record the date / version where relevant.
4. Reproduce important results through a small experiment.
5. Add limitations, open questions and next steps.
6. Link related concepts rather than creating duplicate notes.
